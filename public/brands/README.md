# Technology logos

Logo assets are self-hosted for this portfolio. See sources.json for source URLs and SHA-256 digests. The Chrome DevTools logo is from the [Chrome DevTools team](https://github.com/ChromeDevTools/devtools-logo), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The [Visual Studio Code icon](https://code.visualstudio.com/brand) uses Microsoft's original artwork. The [Zid mark](https://brand.zid.sa/logo) uses the logomark path from Zid's English lockup.

Each skill badge uses a 20 × 20 pixel logo box. Chrome DevTools, Visual Studio Code, and the [Pinokio app icon](https://github.com/pinokiocomputer/pinokio/blob/main/assets/icon_small.png) retain their supplied colors. The remaining marks use the site's accent color, with a small optical inset for solid square marks.
